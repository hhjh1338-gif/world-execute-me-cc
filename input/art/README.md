# 图片输入清单

默认使用代码绘制的几何占位图。可把自己有权使用的 PNG 放在这里，以 ID 命名；未提供或损坏的图片继续使用占位图并在页面提示。

当前成片加载 28 张：

`A1 A3 A4-1 A4-8 A5 A6 B1 B2 B3 B4 C1 C4 C5 C6 E1 E2 F2 F3 F4 F5 F6 G2 G3 G4 G5 G6 N1 P1`

例如 `input/art/A1.png` 是全身角色图，`A3.png` 是头像。角色图应保留透明背景并保证主体未裁断；仅仅提供相同文件名，不保证角色尺寸、定位和动作视觉与原片一致。

N1/P1 用于片尾预告／宣传画面。公开演示使用中性卡片。原制作的音乐封面和另一游戏截图不在包中，不能据此认为它们可以随代码许可证再分发。

恢复原作视觉还需要逐图许可与完整来源记录。现有角色参考线索见根目录 `NOTICE.md`，不要把全部 AI 生成图自动视为无来源限制。
