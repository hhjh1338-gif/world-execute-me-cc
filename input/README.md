# 可选的本地素材

不放任何素材，也可以启动几何占位演示。演示保留时间轴、剧情文字与动画机制，但不是原 MV 的美术、歌曲或最终视觉效果。

只放入你有权使用的文件。这里的音视频、歌词和图像默认被 `.gitignore` 排除，不随源代码 ZIP 分发。导入后刷新页面。

| 路径 | 内容 |
| --- | --- |
| `input/art/A1.png` 等 | 与 [图片清单](art/README.md) ID 对应的 PNG |
| `input/lyrics.en.lrc` | 英文 LRC，行格式为 `[mm:ss.xxx]文字`，按时间排列 |
| `input/lyrics.zh.json` | 形如 `{"lines":[{"zh":"自备第1行"},{"zh":"自备第2行"}]}` 的 UTF-8 JSON |
| `input/edited_song.wav` | 已按项目时间轴编辑后的音频，不是直接改名的原曲 |

原作时间轴有 129 个歌词行索引；不同版本歌词若合行／拆行不同，需要先对齐行号，否则字幕可能与画面错位。包中没有完整歌词或译文。

## 从自己的音源生成编辑音轨

Python 环境需要已有 `numpy`、`soundfile`；使用 `--rate` 重采样时另需 `scipy`。工具不会自动安装这些依赖。

```powershell
python CC/tools/audio_edit.py --src "你的音源路径.flac" --rate 48000
```

工具按 `CC/script/timeline.json` 在指定位置加入倒流段，并输出 `input/edited_song.wav`。`--shift-ms` 用于输入音源相对于时间轴的偏移校正；正值表示输入音源较晚，裁去前面的对应时长。原制作使用过 `1.02` 毫秒校正，但这个值不一定适合你的音源，不能照抄成通用设置。

预览音轨不含所有界面音效；有声视频导出会按事件表混合程序生成的界面音效，并应用时间轴中设定的 67 毫秒声音延迟。不要提前在导入的 WAV 中再叠加一次延迟。

如果只想验证流程，可使用静音演示，不需要歌曲文件。
